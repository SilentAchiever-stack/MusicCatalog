Built to deepen my React fundamentals — specifically state management, component architecture, and handling dynamic data in a way that scales. Music apps have a distinct UX pattern: browsing, filtering, playing. Replicating that pattern in React taught me how to think in components, not just in pages.

What made it hard

Managing playback state across components without it becoming spaghetti. Getting the data flow right — so that playing a song in one component updates UI in another — was a clean lesson in lifting state and thinking architecturally.
